# Five-minute demo

**0:00–0:30** — “Before sending an engineer to an EV installation site, can we establish trustworthy location and property context digitally?”

**0:30–1:00** — Show the request form and explain that the browser sends a business request, while a server-side agent selects discovered MCP capabilities.

**1:00–3:15** — Load the Desert Ridge Marketplace demo and run it. Call out the **DEMO FIXTURE** badge, the observable Agent Activity timeline, and the hard address-resolution gate.

**3:15–4:15** — Review site identity, property intelligence, jurisdiction context, operating area, and evidence drawer. Point out that jurisdictional context is not permit determination and that engineering gaps remain.

**4:15–5:00** — “The system never asks a model to invent physical site facts. Precisely provides trusted evidence; the agent decides which information is needed and what should happen next.” The hypothesis is less avoidable pre-survey work, better field preparation, and an auditable request-to-survey flow.
