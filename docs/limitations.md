# Limitations

- Live data availability depends on the enabled Precisely products and action contracts.
- Dynamic local tool mapping intentionally uses conservative name matching; inspect `npm run mcp:tools` for a new deployment.
- Hosted gateway actions are not guessed without a describable current schema.
- InstallIQ does not determine electrical capacity, transformer or panel capacity, utility interconnection, permit approval, physical obstructions, cost, or installation approval.
- Operating-area distance is straight-line and local; it is not route time.
- This interview prototype is ephemeral: it has no authentication, database, CRM, dispatching, or report export.
